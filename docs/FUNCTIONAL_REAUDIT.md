## Fixes

1. Reject all public-testnet operator HTTP mutations before any trustee handler
   or background attack job can execute; private CLI control remains separate.
2. Preserve a field when the report editor selects “Keep current proposal.”
3. Reject malformed, encrypted and empty/scanned PDFs with a readable error
   before model work, and give report select controls explicit accessible names.
4. Preserve and cryptographically recheck surviving signature sidecars during
   reorganization, instead of deleting all signature evidence. A verified
   replacement sidecar can replace an older cached payload.
5. Rebuild current source in the full-project gate, discover the browser when
   possible, and isolate local runs from inherited public-network flags.
6. Retry interrupted dependency transfers three times at most. Other install
   failures still stop immediately. Exclude private tool configuration,
   historical broadcasts and generated exports from the container context.
7. Keep the selected round visible after its report is sealed and closed; give
   citation links usable touch targets and add missing policy/specification anchors.
