# Limits of the current build

Local gates and actual Monad testnet execution demonstrate real computation
over explicitly SIMULATED inputs.
They do not establish deployment readiness, institutional participation or climate
impact. Current gate evidence is indexed in [BUILD_STATUS.md](BUILD_STATUS.md).

- All trustee roles run on one host with separate keys and stores. Host compromise
  defeats that separation; no regulator, association or university operates a node.
- Two trustees can reconstruct each plant. All other plants can infer the remaining
  plant from the aggregate. Overlapping cohorts can expose differences. Minimum
  size and the coverage policy do not prevent those attacks.
- Public report hashes permit guessing; threshold badges reveal comparison bits.
  Archived X25519 ciphertexts have a harvest-now/decrypt-later risk. The system is
  not fully post-quantum secure.
- Pedersen binding, ECDSA and Groth16 have classical assumptions. The single project
  setup contribution and application curve code have no independent production
  security audit. Dependency advisories and accepted static findings are disclosed.
- The local operator adapter is unauthenticated, uses known synthetic accounts and
  refuses non-Anvil chains. It must not become a public testnet or production API.
- The public export is read-only. Actual Monad role writes use random private
  keys and a private journal; the public governor HTTP write path is disabled.
  Hosting and physical-phone tests remain owner responsibilities.
- Browser openings remain in session storage until cleared. This supports recovery
  but exposes them to a compromised origin or script. File backups contain secrets.
  Clearing a tab is not a claim of forensic erasure.
- Source grounding and physics cannot establish report truth. Model failures,
  disclosed repairs, a false block on one valid report and evaluation scope are in
  [AI_CARD.md](AI_CARD.md). No accuracy on real reports is claimed.
- The direct-only cement plausibility model omits regulatory boundary cases. Other
  products/countries can select round parameters but need their own validated
  measurement, functional-unit and regulatory adapters.
- The sector denominator and cohort are declarations. "Representative" is the
  contract's coverage/minimum-size policy flag, not a statistical or legal finding.
- A signature proves control of a key under the protocol, not accreditation,
  competence, identity vetting or an independent assurance opinion.
- Local browser recomputation trusts the chosen frontend build, deployment anchor
  and RPC for chain history. It is not a light client or a finality proof.
- No regulator has accepted this output. The calculator shows gross illustrative
  scenarios, not payable CBAM liability. Regional mark-up treatment and full
  comparability of the association declaration remain UNVERIFIED.
- Model tokens and execution time are measured; energy, water, lifecycle emissions
  and real-world emissions reductions are not. Fee/default changes are not physical
  decarbonisation.
- Turkish text requires native review. No publication, submission, public phone
  test or remote CI result is inferred from passing local gates.
